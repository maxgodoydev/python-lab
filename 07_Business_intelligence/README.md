## 🧩 O problema

Um indicador só é confiável se a base por trás dele for confiável. O Python pode preparar, validar e automatizar etapas ao redor de uma ferramenta de BI, enquanto o Power BI cumpre o papel de modelar e visualizar. As duas trabalham em conjunto; uma não substitui a outra.

<img src="../Assets/divider.svg" alt="" width="100%">

## 👥 Para quem

Para quem quer entender como Python e BI se complementam. E para quem avalia e quer ver preocupação com a qualidade dos dados que alimentam um dashboard.

<img src="../Assets/divider.svg" alt="" width="100%">

## 🧭 Como funciona

**📚 Assuntos, na ordem de estudo**

1. Preparação e transformação de dados
2. Análise e validação de bases
3. Geração e validação de indicadores
4. Análises exploratórias para apoiar decisões
5. Automação de relatórios
6. Integração de Python com Power BI
7. Integração entre Python, SQL e ferramentas de BI
8. Aplicações práticas em dashboards e indicadores

**💡 Exemplos de aplicação**

- Preparar dados antes de carregá-los em uma ferramenta de BI
- Validar informações usadas em indicadores
- Automatizar tarefas recorrentes de preparação de relatórios
- Comparar resultados e identificar variações
- Apoiar análises de desempenho comercial, financeiro ou operacional

**➡️ Sequência.** Depende do módulo 06, pois a preparação e a validação de dados usam as mesmas ferramentas. A parte de SQL conversa com o módulo 08.

**🗂️ Organização.** A organização interna será definida conforme o conteúdo real. Propostas iniciais de subpastas: `Power_bi/`, `Indicadores/` e `Automacao_relatorios/`, criadas somente quando houver material.

**📦 Dados.** Serão fictícios ou de fontes públicas adequadas, com origem e condições de uso documentadas.
